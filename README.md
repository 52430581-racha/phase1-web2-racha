# Smart Home System

## Description

A responsive frontend Smart Home website developed
for CSCI426 Advanced Web Programming.

## Technologies

- ReactJS
- Bootstrap
- JavaScript
- React Router
- Vite

## Pages

- Home
- About
- Services
- Contact
- Contact List

## Dynamic Functionality

Users can submit contact details, view saved entries
in a table, and delete entries.

Data is stored in the browser using localStorage.

## Setup

1. Clone this repository.
2. Run npm install.
3. Run npm run dev.
